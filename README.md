## **About**

Speed Master F1 is a full-stack web application dedicated to Formula 1 enthusiasts. It offers a comprehensive platform to manage driver details, team information, race records, and challenges your knowledge with engaging quizzes.

## **Key Features**

1. **Driver Database 🚀**
   - CRUD Operations: Manage your favorite drivers effortlessly.
   - Comprehensive Information: Access details such as name, age, and nationality.
2. **Team Management 🏁**
   - Build Your Dream Team: Explore and organize teams with ease.
   - Driver Lineup: Track and update the driver lineup for each team.
3. **Race Records 🌍**
   - CRUD Operations: Keep tabs on every race with winner details, location, and winning time.
   - Stay Updated: Always know who's dominating the tracks.
4. **Challenge Your Knowledge 🏆**
   - Driver Quiz: Test your knowledge about F1 drivers.
   - Team Quiz: Prove your expertise on F1 teams.

## **Installation**

1. **Navigate to Project Directory:**

   ```bash
   cd DS3103-Webutvikling-2023
   cd ReactApplication
   cd WebAPI
   ```

2. **Run Backend**

   ```bash
   cd DS3103-Webutvikling-2023/WebAPI
   dotnet run
   ```

3. **Run Frontend** 

   ```bash
   cd DS3103-Webutvikling-2023/ReactApplication
   npm install
   npm run dev
   ```

## **Usage**

1. **Access the App:**
   Open your browser and go to [http://localhost:3000](http://localhost:3000/)
